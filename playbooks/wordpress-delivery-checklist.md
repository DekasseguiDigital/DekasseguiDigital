# 🚀 WordPress Delivery Checklist

Checklist oficial da Dekassegui Digital para entrega de projetos WordPress.

---

# Antes de iniciar

- [ ] Backup completo
- [ ] Ambiente atualizado
- [ ] Credenciais organizadas
- [ ] Confirmar escopo aprovado

---

# WordPress

- [ ] WordPress atualizado
- [ ] Tema atualizado
- [ ] Plugins atualizados
- [ ] Plugins desnecessários removidos

---

# Elementor

- [ ] Layout revisado
- [ ] Responsividade Desktop
- [ ] Responsividade Tablet
- [ ] Responsividade Mobile
- [ ] Espaçamentos revisados
- [ ] Tipografia padronizada
- [ ] Cores conferidas

---

# Performance

- [ ] LiteSpeed configurado
- [ ] Cache limpo
- [ ] CSS otimizado
- [ ] JS otimizado
- [ ] Lazy Load ativo
- [ ] WebP quando possível

---

# SEO

- [ ] Título da página
- [ ] Meta descrição
- [ ] Open Graph
- [ ] Sitemap
- [ ] Robots.txt
- [ ] Schema básico

---

# Formulários

- [ ] Formulário funcionando
- [ ] SMTP configurado
- [ ] Teste de envio realizado
- [ ] Mensagens traduzidas

---

# Segurança

- [ ] Login protegido
- [ ] Usuários revisados
- [ ] Backup automático
- [ ] Atualizações automáticas configuradas
