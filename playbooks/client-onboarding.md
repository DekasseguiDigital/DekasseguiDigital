# 🤝 Client Onboarding

Processo oficial de entrada de novos clientes na Dekassegui Digital.

---

# Objetivo

Garantir que todos os projetos iniciem organizados, com escopo claro, comunicação eficiente e documentação completa.

---

# Fluxo

## 1. Primeiro contato

- [ ] WhatsApp
- [ ] Instagram
- [ ] Facebook
- [ ] Indicação
- [ ] Site
- [ ] Outro

---

## 2. Descoberta

Entender:

- Quem é o cliente
- Qual é o negócio
- Objetivos
- Público-alvo
- Prazo
- Orçamento

---

## 3. Briefing

Solicitar todas as informações necessárias.

Exemplos:

- Logo
- Cores
- Fotos
- Textos
- Referências
- Domínio
- Hospedagem

---

## 4. Auditoria

Sempre analisar o ambiente antes de iniciar.

Verificar:

- WordPress
- Plugins
- Tema
- Elementor
- Performance
- Segurança
- SEO
- Backup

---

## 5. Proposta

Enviar:

- Escopo
- Valor
- Prazo
- Forma de pagamento
- Condições

---

## 6. Aprovação

- [ ] Cliente aprovou
- [ ] Entrada recebida
- [ ] Projeto autorizado

---

## 7. Organização

Criar:

- Pasta do projeto
- Documentação
- GitHub (quando necessário)
- Backup inicial

---

## 8. Desenvolvimento

Iniciar somente após:

- Escopo aprovado
- Conteúdo recebido
- Pagamento confirmado

---

# Princípios

Nunca começar um projeto sem briefing.

Nunca desenvolver sem escopo definido.

Toda decisão importante deve ficar documentada.

---

> Um bom projeto começa muito antes da primeira linha de código.
