# 🚀 Sobre

Sou fundador da **Dekassegui Digital**, uma iniciativa criada para desenvolver soluções digitais organizadas, reutilizáveis e de alta qualidade.

Atuo principalmente com:

- WordPress
- Elementor
- SEO
- Performance
- Inteligência Artificial
- Automação

Meu principal projeto é o **DDOS (Dekassegui Digital Operating System)**, um sistema vivo de documentação criado para transformar conhecimento adquirido em projetos reais em processos reutilizáveis.

O objetivo não é apenas entregar sites.

É criar um método capaz de tornar cada novo projeto melhor do que o anterior.
