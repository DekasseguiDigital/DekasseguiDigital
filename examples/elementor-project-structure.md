# 🏗 Elementor Project Structure

Estrutura recomendada para projetos desenvolvidos com Elementor Pro.

---

## Organização

```text
Header

Hero

Sobre

Serviços

Diferenciais

Depoimentos

FAQ

CTA Final

Footer
```

---

## Containers

- Container principal
- Containers internos reutilizáveis
- Evitar excesso de níveis

---

## Classes

```text
.section
.container
.grid
.card
.btn-primary
.btn-secondary
```

---

## Performance

- Containers ao invés de Seções
- SVG sempre que possível
- Lazy Load
- WebP
- CSS mínimo

---

## Boas práticas

✔ Sem CSS inline desnecessário

✔ Sem IDs aleatórios

✔ Classes reutilizáveis

✔ Layout editável por qualquer desenvolvedor

✔ Mobile First

---

## Utilizado em

- JK Fukuoka Tour
- Japão Guias de Turismo
- Landing Pages Dekassegui Digital

---

> Um layout bonito deve continuar bonito mesmo quando outro desenvolvedor assumir o projeto.
